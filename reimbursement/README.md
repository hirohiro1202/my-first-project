# 立替明細管理アプリ（MVP）

廣中さんの立替経費を、案件別・日付別に整理するWebアプリです。

## 現在実装済み
- レスポンシブなダッシュボード
- 立替明細の登録・編集・削除
- 案件登録、クライアント名管理
- 案件別／月別／精算状況別の絞り込み
- 案件別集計、今月合計、未精算額、当日登録件数
- CSVによる明細書書き出し
- ICOCA履歴CSVの読み込み、案件割り当て、明細登録
- ブラウザのlocalStorageへの保存

## 起動
GitHub Pagesなどで `reimbursement/` フォルダを公開するか、ローカルで次を実行します。

```bash
python3 -m http.server 3000
```

その後 `http://localhost:3000/reimbursement/` を開きます。

## 保存とプライバシー
現段階ではデータは**開いているブラウザのlocalStorage内**に保存されます。別端末・別ブラウザへの同期、ログイン、バックアップはまだありません。共有端末で使用しないでください。実運用前にクラウドDB・認証・バックアップを実装します。

## ICOCAについて
ICOCAの公式アカウントやApple Payへ直接接続する機能はありません。ユーザーが取得したCSV履歴を取り込む方式です。実際のCSV列名に合わせてインポーターを調整する必要があります。

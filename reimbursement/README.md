# 立替明細管理アプリ（MVP）

廣中さんの立替経費を、案件別・日付別に整理するWebアプリです。

## 現在実装済み
- レスポンシブなダッシュボード
- 立替明細の登録・編集・削除
- 案件登録、クライアント名管理
- 案件別／月別／精算状況別の絞り込み
- 案件別集計、今月合計、未精算額、当日登録件数
- CSVによる明細書書き出し
- 複数ファイル一括取込（CSV・TSV・Excel・PDF・画像・JSON・テキスト・iCal）\n- ICOCA・カード明細の列名を自動判定し、案件割り当て、明細登録\n- 領収書・レシート画像のブラウザ内OCR（日本語・英語）\n- PDFテキスト抽出、iCalから撮影・出張・打合せなどの予定候補を抽出\n- 読み取り結果を登録前に確認し、重複取り込みを抑制
- ブラウザのlocalStorageへの保存

## 起動
GitHub Pagesなどで `reimbursement/` フォルダを公開するか、ローカルで次を実行します。

```bash
python3 -m http.server 3000
```

その後 `http://localhost:3000/reimbursement/` を開きます。

## 保存とプライバシー
現段階ではデータは**開いているブラウザのlocalStorage内**に保存されます。別端末・別ブラウザへの同期、ログイン、バックアップはまだありません。共有端末で使用しないでください。実運用前にクラウドDB・認証・バックアップを実装します。

## ファイル取込について\n画像OCRは初回のみ外部CDNからTesseract.jsを読み込みます。ExcelはSheetJS、PDFはPDF.jsを利用します。ファイル内容はブラウザ内で処理し、外部のAIサービスへアップロードしません。PDFが画像のみのスキャン形式の場合は、現状のテキスト抽出では認識できず、別途PDFページOCRの拡張が必要です。HEICはブラウザ対応状況によりJPEG/PNGへの変換が必要です。iCalは予定候補として表示し、経費額を推測して登録しません。\n\n## ICOCAについて
ICOCAの公式アカウントやApple Payへ直接接続する機能はありません。ユーザーが取得したCSV履歴を取り込む方式です。実際のCSV列名に合わせてインポーターを調整する必要があります。
